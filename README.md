# Employee Performance Analysis

An Applied Data Science project focused on analyzing employee data using data preprocessing, classification, regression, clustering, and association rule mining.

## Technologies
- Python
- Pandas, NumPy
- Matplotlib, Seaborn
- Scikit-learn
- Jupyter Notebook

## Project Files
- `Employee_Performance.ipynb` — Data analysis, model implementation, and visualizations.
- `ADS_project_report.pdf` — Detailed explanation of the methodology, algorithms, and results.
- `combined_employee_dataset_1.csv` — Dataset used for the analysis.

## Dataset
Source: [Employee Performance Dataset on Kaggle](https://www.kaggle.com/datasets/ziya07/employee-performance-dataset)

## How to Run
1. Install Python and Jupyter Notebook.
2. Install the required Python libraries.
3. Open `Employee_Performance.ipynb` and run the cells.
